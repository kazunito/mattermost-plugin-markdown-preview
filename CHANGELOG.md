# Changelog

## 0.1.1 - 2026-08-25

- Render `.md` and `.markdown` attachments in the Mattermost file preview modal.
- Add a paper-like document view, generated table of contents, and source view.
- Add styles for headings, tables, code blocks, quotes, images, and responsive layouts.
- Fix Mattermost 11.8 compatibility by using Mattermost CSS variables instead of an unavailable theme prop.
